# Implement the Gähler Shield tiling

Add the dodecagonal Shield presentation using squares, equilateral triangles, and marked shield tiles.

## Acceptance criteria

- Transcribe the self-similar Shield rule and its four standard marked/oriented prototile states.
- Preserve the vertex-cross matching information and twelvefold hierarchy.
- Generate a gap-free patch covering the requested disc.
- Test substitution area, all states, legal geometry, coverage, rendering, and registry integration.
- Cite the exact source rule used for arrows and vertex crosses; attribute reused diagrams/assets and verify license compatibility.
- Document its model-set status and MLD relation to Socolar; typecheck, tests, and build pass.

## References

- [Gähler, “Crystallography of Dodecagonal Quasicrystals” (1988)](https://www.math.uni-bielefeld.de/~gaehler/publications.html) — original source and author-hosted publication record.
- [Gähler, “Matching rules for quasicrystals: the composition-decomposition method”](https://www.math.uni-bielefeld.de/~gaehler/papers/stlouis92.pdf) — matching-rule method and dodecagonal example.
- [Tilings Encyclopedia: Shield](https://tilings.math.uni-bielefeld.de/substitution/shield/) — explicit substitution, arrow, and vertex-cross diagrams.
- [Local rare-tilings literature catalog](../rare-aperiodic-tilings.md) — project context and MLD notes.
