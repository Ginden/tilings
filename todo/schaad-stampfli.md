# Implement the Schaad–Stampfli dodecagonal tiling

Add the 2021 twelvefold substitution with inflation factor \(1+\sqrt3\).

## Acceptance criteria

- Implement squares, 30° rhombs, and the published half-triangle substitution variants.
- Select and document a deterministic combination of the nine possible recombinations.
- Generate a gap-free requested patch with repeated twelvefold rosettes.
- Test inflation/area, every carrier type, coverage, rendering, and registry integration.
- Cite the publication and explain the chosen variant; typecheck, tests, and build pass.
