# Implement a representative CAST tiling

Add a well-documented member of Pautze’s cyclotomic aperiodic substitution tiling family.

## Acceptance criteria

- Choose one published CAST member not already represented by an existing generator and record why it was selected.
- Implement its exact cyclotomic prototiles, orientation states, and substitution.
- Generate a gap-free requested patch and retain the intended rotational order.
- Test cyclotomic geometry, substitution area, classes, coverage, rendering, and registry integration.
- Document that the UI entry is a representative member, not the entire parameterized family; typecheck, tests, and build pass.
