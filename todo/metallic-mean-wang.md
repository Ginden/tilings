# Implement metallic-mean Wang tiles

Add a selectable or representative member of Labbé’s metallic-mean Wang family.

## Acceptance criteria

- Start with a published \(n\ge2\) member so the task does not duplicate Ammann’s \(n=1\) system; document the chosen parameter.
- Encode the exact finite Wang set and self-similar rule with expansion given by the positive root of \(x^2-nx-1\).
- Generate legal gap-free patches and expose the quadratic hierarchy.
- Test all tile states, edge legality, expansion, coverage, rendering, and registry integration.
- Make the parameter scope clear in the UI and README; typecheck, tests, and build pass.
