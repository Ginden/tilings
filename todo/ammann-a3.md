# Implement Ammann A3

Add Ammann’s three-prototile golden-ratio substitution tiling, including its marked edge constraints.

## Acceptance criteria

- Transcribe the A3 prototiles and substitution from a primary or archival source cited in `rare-aperiodic-tilings.md`.
- Register all marked/oriented tile states with accurate metadata and a stable ID.
- Generate a gap-free patch covering the requested disc and preserve the golden-ratio hierarchy.
- Add substitution-area, tile-class, coverage, rendering, and registry tests.
- Cite the exact source figure/page used for geometry and substitutions in code comments; attribute any reused assets and verify license compatibility.
- Document the tiling in `README.md`; typecheck, tests, and production build pass.

## References

- [Ammann, Grünbaum, and Shephard, “Aperiodic tiles” (1992)](https://doi.org/10.1007/BF02293033) — primary published account of Ammann’s tile sets.
- [Tilings Encyclopedia: Ammann A3](https://tilings.math.uni-bielefeld.de/substitution/ammann-a3/) — substitution diagram and prototile metadata.
- [Local rare-tilings literature catalog](../rare-aperiodic-tilings.md) — project context and further bibliography.
