# Implement Ammann A3

Add Ammann’s three-prototile golden-ratio substitution tiling, including its marked edge constraints.

## Acceptance criteria

- Transcribe the A3 prototiles and substitution from a primary or archival source cited in `rare-aperiodic-tilings.md`.
- Register all marked/oriented tile states with accurate metadata and a stable ID.
- Generate a gap-free patch covering the requested disc and preserve the golden-ratio hierarchy.
- Add substitution-area, tile-class, coverage, rendering, and registry tests.
- Document the tiling in `README.md`; typecheck, tests, and production build pass.
