# Implement the Tribonacci Rauzy-fractal tiling

Add a planar realization of the Tribonacci substitution and its Rauzy-fractal prototiles.

## Acceptance criteria

- Implement the substitution \(1\mapsto12, 2\mapsto13, 3\mapsto1\) using a documented fractal or equivalent topological realization.
- Extend polygon rendering only as needed to represent the chosen finite approximation accurately and efficiently.
- Generate a gap-free requested patch with all three tile classes.
- Test substitution counts, scale/area, fractal approximation continuity, coverage, rendering, and registry integration.
- Cite the exact iterated-function/topological rule and state the approximation tolerance used by rendering tests; attribute reused assets and verify license compatibility.
- Cite Rauzy and the later topological-substitution equivalence; typecheck, tests, and build pass.

## References

- Rauzy, “Nombres algébriques et substitutions” (1982), *Bulletin de la Société Mathématique de France* 110, 147–178 — original Tribonacci central-tile construction; see the full citation in the local catalog.
- [Bédaride, Hilion, and Jolivet, “Topological substitution for the aperiodic Rauzy fractal tiling” (2018)](https://doi.org/10.24033/bsmf.2762) — explicit topological substitution and equivalence proof.
- [Author preprint (arXiv:1603.02790)](https://arxiv.org/abs/1603.02790) — openly accessible version.
- [Tilings Encyclopedia: Tribonacci](https://tilings.math.uni-bielefeld.de/substitution/tribonacci/) — substitution and fractal summary.
