# Implement Penrose’s hexagonal \(1+\epsilon+\epsilon^2\) tiling

Add Roger Penrose’s 1997 marked hexagon–triangle-derived hierarchical aperiodic set.

## Acceptance criteria

- Derive the three prototiles, mirror states, markings, and hierarchy from Penrose’s published construction.
- Do not substitute a P2/P3 or generic hexagonal-grid approximation.
- Generate a gap-free central patch with every required marked/oriented state.
- Add geometry, hierarchy, coverage, rendering, and registry tests.
- Cite the exact page/figure used for each prototile, marking, and hierarchy rule; attribute reused assets and verify license compatibility.
- Add metadata and README documentation; typecheck, tests, and production build pass.

## References

- Penrose, “Remarks on tiling: Details of a (1+ε+ε²)-aperiodic set” (1997), in *Mathematics of Long-Range Aperiodic Order*, pp. 467–497 — primary construction; see the full citation in the local catalog.
- [Baake and Grimm, “Hexagonal inflation tilings and planar monotiles” (2012)](https://doi.org/10.3390/sym4040581) — later analysis and reconstruction context.
- [Author preprint (arXiv:1210.3967)](https://arxiv.org/abs/1210.3967) — openly accessible secondary source.
- [Local rare-tilings literature catalog](../rare-aperiodic-tilings.md) — primary bibliographic record and project scope.
