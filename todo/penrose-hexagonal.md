# Implement Penrose’s hexagonal \(1+\epsilon+\epsilon^2\) tiling

Add Roger Penrose’s 1997 marked hexagon–triangle-derived hierarchical aperiodic set.

## Acceptance criteria

- Derive the three prototiles, mirror states, markings, and hierarchy from Penrose’s published construction.
- Do not substitute a P2/P3 or generic hexagonal-grid approximation.
- Generate a gap-free central patch with every required marked/oriented state.
- Add geometry, hierarchy, coverage, rendering, and registry tests.
- Add metadata and README documentation; typecheck, tests, and production build pass.
