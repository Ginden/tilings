# Implement Ammann A4

Add Ammann’s two-prototile silver-mean substitution presentation of octagonal order.

## Acceptance criteria

- Use the actual nonconvex/decorated A4 prototiles and silver-mean substitution, not A5 rhombs relabelled as A4.
- Preserve the marked/oriented states needed for local forcing and register accurate metadata.
- Generate a gap-free requested patch and show the substitution hierarchy.
- Test child-area conservation, all prototile states, coverage, rendering, and registry integration.
- Cite the exact source figure/page used for geometry, decorations, and substitutions in code comments; attribute any reused assets and verify license compatibility.
- Document its MLD relationship with Ammann–Beenker; typecheck, tests, and build pass.

## References

- [Ammann, Grünbaum, and Shephard, “Aperiodic tiles” (1992)](https://doi.org/10.1007/BF02293033) — primary published account of Ammann’s tile sets.
- [Tilings Encyclopedia: Ammann A4](https://tilings.math.uni-bielefeld.de/substitution/ammann-a4/) — substitution diagram, decoration, and MLD notes.
- [Local rare-tilings literature catalog](../rare-aperiodic-tilings.md) — project context and further bibliography.
