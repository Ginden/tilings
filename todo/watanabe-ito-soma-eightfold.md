# Implement the Watanabe–Ito–Soma eightfold tiling

Add the independent octagonal self-similar square-and-rhomb construction published in 1986–87.

## Acceptance criteria

- Reconstruct the published subdivision of octagonal unit cells and its square/rhomb prototiles.
- Keep it geometrically and algorithmically distinct from the existing Ammann–Beenker multigrid.
- Generate a gap-free patch covering the requested disc.
- Test substitution area, tile shapes, eightfold structure, coverage, rendering, and registry integration.
- Use the explicit 1995 version to resolve the ambiguity in the 1986–87 descriptions, and cite the exact figure/rule in code comments; attribute reused assets and verify license compatibility.
- Cite both proceedings and journal sources where appropriate; typecheck, tests, and build pass.

## References

- Watanabe, Soma, and Ito, “Nonperiodic tessellation with eightfold rotational symmetry” (1987), *Acta Crystallographica A* 43, 133–134 — original journal announcement; see the full citation in the local catalog.
- [Tilings Encyclopedia: Watanabe–Ito–Soma 8-fold](https://tilings.math.uni-bielefeld.de/substitution/watanabe-ito-soma-8-fold/) — explicit 1995 rule plus the proceedings and journal bibliography.
