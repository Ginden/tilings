# Implement a quadratic-irrational striped Wang set

Add one concrete member of the Kari–Labbé–Mostert quadratic-irrational Wang family.

## Acceptance criteria

- Choose and document an irrational pair \((\alpha,\beta)\) from one real quadratic field that is not already covered by the metallic-mean task.
- Encode the corresponding finite striped Wang set from the 2026 construction.
- Generate patches satisfying every local edge/stripe rule and measure the intended stripe densities.
- Test tile completeness, edge legality, density convergence, rendering, and registry integration.
- Cite the chosen theorem/construction parameters and record the generated tile tuples in code comments; attribute reused assets and verify license compatibility.
- Label the source as a 2026 preprint and avoid claims not established for every family member; typecheck, tests, and build pass.
