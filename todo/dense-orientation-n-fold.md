# Implement a general dense-orientation \(n\)-fold example

Add one non-Shuriken member of the published dense-tile-orientation substitution family.

## Acceptance criteria

- Select a published \(n\in\{2,3,4,5,6,8\}\) construction not duplicated by another task and document the choice.
- Implement its exact prototiles, substitution, and irrational relative rotation.
- Generate a gap-free requested patch with demonstrably increasing orientation diversity.
- Test substitution area, classes, orientation statistics, coverage, rendering, and registry integration.
- Cite the selected example and rule number, and test its stated irrational-angle invariant; attribute reused assets and verify license compatibility.
- Name the UI entry as a representative example rather than the whole family; typecheck, tests, and build pass.

## References

- [Frettlöh, Say-awen, and de las Peñas, “Substitution tilings with dense tile orientations and n-fold rotational symmetry” (2017)](https://doi.org/10.1016/j.indag.2016.11.009) — primary family construction.
- [Author preprint (arXiv:1602.00518)](https://arxiv.org/abs/1602.00518) — openly accessible rules and figures.
